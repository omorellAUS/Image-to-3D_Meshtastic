Free Image-to-3D — Downloadable Package
=======================================

End user steps:
1. Download the ZIP from the GitHub repo and extract it.
2. Double-click start.bat.
3. First run creates the environment and installs packages.
4. If TripoSR is missing, the launcher tries to clone it (Git required).
5. Browser opens at http://127.0.0.1:7860

User requirements:
- Windows 10/11
- Python 3.10 or 3.11 on PATH
- NVIDIA GPU (6–8 GB+ VRAM) + drivers
- Internet on first run

The launcher handles setup automatically after that.
